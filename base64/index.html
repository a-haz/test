FAQ

What is Base64?

Base64 is an encoding that represents binary data using 64 printable characters (A–Z, a–z, 0–9, + and /). It's used wherever binary data has to travel through text-only channels: email attachments, data URLs, JSON payloads, basic HTTP auth headers, JWT tokens and more.

Is Base64 encryption?

No. Base64 is encoding, not encryption — anyone can decode it instantly (this page proves it). Never use Base64 to "hide" secrets. If you need confidentiality, use real encryption.

What is URL-safe Base64?

Standard Base64 uses + and /, which have special meanings in URLs. The URL-safe variant (RFC 4648 §5) substitutes - and _ and usually drops the = padding, so the result can be put directly in a URL or filename. JWTs use this variant.

Why does my decode fail?

Usually stray whitespace or line breaks inside the string, a truncated string, or mixing the standard and URL-safe alphabets. This tool strips whitespace automatically and accepts both alphabets when decoding.
