Case Converter

Paste text, click a style, copy the result. Works for prose and for programming identifiers.

When to use each style

  • Title Case — headlines and titles. Small words (a, an, the, of, in…) stay lowercase unless first or last.
  • Sentence case — normal prose: first letter of each sentence capitalized.
  • camelCase / PascalCase — variables and class names in JavaScript, Java, C#, Go…
  • snake_case — Python variables, database columns, file names.
  • kebab-case — URLs, CSS classes, CLI flags.

FAQ

How does the programming-case conversion split words?

It splits on spaces, punctuation, underscores and hyphens, and also on letter-case boundaries — so XMLHttpRequest becomes xml_http_request in snake_case. Numbers stick to the word they follow.

Does Title Case follow a specific style guide?

It follows the common convention shared by AP and Chicago: capitalize all words except short articles, conjunctions and prepositions — but always capitalize the first and last word. Style guides differ on edge cases, so give headlines a quick read.

Is my text stored or sent anywhere?

No — conversion happens instantly in your browser on a static page. Nothing is transmitted or saved.
