Hash Generator

Generate SHA-256, SHA-1, SHA-384 and SHA-512 hashes from text or a file. Computed locally with the Web Crypto API — your input never leaves your device.

FAQ

What is a hash used for?

A cryptographic hash turns any input into a fixed-length fingerprint. The same input always produces the same hash, and even a one-character change produces a completely different one. Hashes are used to verify file integrity (does this download match the published checksum?), to index data, and — with proper salting — to store passwords.

Why no MD5?

Browsers' built-in Web Crypto API doesn't provide MD5 because it's cryptographically broken. We chose not to bundle a third-party MD5 library so this tool stays dependency-free and everything runs in native code. For integrity checks, prefer SHA-256.

Is SHA-1 safe?

No, not for security. Practical collision attacks against SHA-1 exist, so it shouldn't be used for signatures or anything adversarial. It's included only because some legacy systems and Git object IDs still use it. Use SHA-256 or stronger.

Can I verify a file download?

Yes — click "Hash a file instead", pick the downloaded file, and compare the SHA-256 against the checksum the publisher provides. If they match exactly, the file is intact. The file is read locally and never uploaded.
