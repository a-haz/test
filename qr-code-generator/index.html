FAQ

Do these QR codes expire or stop working?

Never. Many "free" QR services route your code through their server and disable it unless you pay — that's the catch. The codes generated here encode your content directly, so they work as long as QR scanning exists. (The flip side: the content can't be edited after printing, since it's baked into the code.)

Is my data uploaded?

No. The QR code is computed entirely in your browser by an open-source JavaScript library bundled with this page. You can disconnect from the internet and it still works.

Which error correction level should I use?

M (15%) is right for most uses. Pick H (30%) if the code will be printed small, might get scuffed, or if you plan to put a logo over the middle. Higher correction makes the code denser, so it needs to be printed slightly larger to stay scannable.

How much can a QR code hold?

Up to about 2,950 bytes — roughly 2,900 characters of plain text. But shorter is better: less content means a coarser, easier-to-scan code. For long URLs, consider a short link.
