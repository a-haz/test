FAQ

What is Unix time?

The number of seconds elapsed since 00:00:00 UTC on January 1, 1970 (the "epoch"), not counting leap seconds. It's the standard machine representation of time across operating systems, databases and APIs because it's a single unambiguous number with no timezone attached.

Seconds or milliseconds?

Unix time is classically in seconds (10 digits in the current era). JavaScript's Date.now() and many APIs use milliseconds (13 digits). This tool auto-detects: values ≥ 100,000,000,000 are treated as milliseconds.

What is the year 2038 problem?

Systems storing Unix time in a signed 32-bit integer overflow on January 19, 2038 (at 2,147,483,647 seconds). Modern 64-bit systems are unaffected, but embedded devices and old file formats may still bite.

Why does my converted date look off by some hours?

Timezones. A timestamp is an absolute instant; the "local time" row renders it in your browser's timezone, while the UTC row is timezone-free. When comparing with a server log, check which timezone the log uses.
