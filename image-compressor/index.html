FAQ

Are my photos uploaded to a server?

No — that's the whole point of this tool. Compression happens with the HTML5 canvas API inside your browser. You can load this page, go offline, and it still works. Most online compressors upload your image to their servers; this one never does.

Which format should I choose?

JPEG is the safe default for photos and is accepted everywhere. WebP compresses 25–35% smaller at similar quality and works in all modern browsers. PNG is lossless and keeps transparency, but produces much larger files for photos — use it for screenshots, logos and graphics with sharp edges.

What quality setting should I use?

70–85% is the sweet spot for photos — big savings with no visible difference at normal viewing sizes. Below 50% you'll start to see compression artifacts. For email attachments or web forms with size limits, also set a max width (1920px covers full-screen viewing; 1200px is plenty for documents).

Does resizing reduce file size more than quality?

Usually yes. Halving the width quarters the pixel count, which typically cuts file size by 60–75% on its own. A 12-megapixel phone photo resized to 1920px wide plus 80% JPEG quality is routinely 10× smaller with no visible loss on screen.

Why does my transparent PNG get a white background?

JPEG doesn't support transparency, so transparent areas are flattened to white when converting. Choose PNG or WebP output to keep transparency.
