FAQ

Is it safe to paste sensitive JSON here?

Yes. This page is a static file with no backend — parsing and formatting happen entirely in your browser using the built-in JSON.parse and JSON.stringify. Nothing is transmitted anywhere. You can even load the page, disconnect from the internet, and it still works.

Why is my JSON invalid?

The most common causes: trailing commas after the last item, single quotes instead of double quotes, unquoted property names, and comments (standard JSON doesn't allow them). The validator above points you at the exact line and column of the first problem.

What's the difference between Format and Minify?

Format pretty-prints the JSON with indentation and newlines so humans can read it. Minify strips all unnecessary whitespace to make the payload as small as possible for transmission or storage. Both validate the JSON first.

Is there a size limit?

Only your browser's memory. Documents in the tens of megabytes format fine on a typical machine.
